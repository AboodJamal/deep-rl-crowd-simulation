================================================================================
TROUBLESHOOTING
================================================================================

❌ PROBLEM 1: Low success rate (~60% or less)
CAUSE: Missing --vec-normalize flag
SOLUTION: ALWAYS use --vec-normalize flag with the correct .pkl file
         python evaluate_vga_drl.py \
             --model models/vga_drl_final.zip \
             --vec-normalize models/vga_drl_stage6_vecnormalize.pkl \
             ...

❌ PROBLEM 2: Trajectories show "jumps" at the end
CAUSE: Outdated evaluate_vga_drl.py (terminal observation bug)
SOLUTION: Use the corrected evaluate_vga_drl.py from this directory
STATUS: ✅ Fixed (pre_step_pos recording implemented)

❌ PROBLEM 3: FileNotFoundError for VGA dataset
CAUSE: Dataset path not found
SOLUTION: Update DATA_DIR in vga_experimental_env.py:
         DATA_DIR = Path("D:/Abdullah Jamal/downloads/VGA-exp/Pedestrian-Experimental-Data")

❌ PROBLEM 4: CUDA out of memory during training
CAUSE: GPU memory insufficient
SOLUTION: Reduce n_envs:
         python train_vga_drl.py --timesteps 2000000 --n-envs 4

❌ PROBLEM 5: Agent circles around goal
CAUSE: Not using deterministic policy during evaluation
SOLUTION: Add --deterministic flag:
         python evaluate_vga_drl.py ... --deterministic

================================================================================
KEY FILES EXPLANATION
================================================================================

TRAINING FILES:
├── vga_experimental_env.py          # Gymnasium environment (VGA setup)
│   - Arena: 10m × 3.5m
│   - Agent radius: 0.2m
│   - Obstacle radius: 0.25m
│   - dt: 0.05s
│   - Observation: 41-dim (36 rays + goal + velocity + heading)
│   - Action: 2-dim continuous (acceleration_x, acceleration_y)
│
├── train_vga_drl.py                 # PPO curriculum training
│   - 6 stages: SOSP → MOSP_A → MOSP_C → MOSP_B → MOSP_D → Mixed
│   - 2M timesteps total
│   - 8 parallel environments
│   - VecNormalize for observation/reward scaling
│   - Advanced Actor-Critic policy (256-256-128 hidden layers)
│
└── evaluate_vga_drl.py              # Evaluation script
    - Loads model + VecNormalize stats
    - Runs on test split (141 trials)
    - Generates trajectories & videos
    - Computes success rate & metrics

TRAINED MODEL FILES:
├── models/vga_drl_final.zip                     # PPO policy (250K params)
├── models/vga_drl_stage6_vecnormalize.pkl      # Normalization stats (CRITICAL!)
└── models/training_summary.json                 # Training statistics

EVALUATION RESULTS:
└── evaluation_final/results/evaluation_results.json
    Contains for each trial:
    - positions: [(x, y), ...] full trajectory
    - success: bool
    - collisions: int
    - steps: int
    - start, goal, obstacles

================================================================================
CRITICAL NOTES
================================================================================

1. ⚠️ ALWAYS use --vec-normalize flag during evaluation!
   The model was trained with VecNormalize, so observations MUST be normalized
   using the same statistics (running mean/var) saved during training.

2. ⚠️ Use models/vga_drl_stage6_vecnormalize.pkl (NOT stage1-5)!
   Only the final stage (stage 6) stats are compatible with vga_drl_final.zip

3. ✅ The evaluate_vga_drl.py includes the trajectory recording fix.
   It records pre_step_pos to avoid the "jump" bug at episode end.

4. 📊 Expected performance variations:
   - SOSP, MOSP_A, MOSP_C: Should be 100%
   - MOSP_B (tight spacing): 98-100%
   - MOSP_D (16 obstacles): 98-100%
   - Overall: 98.5-99.5%

5. 🎯 Dataset split is deterministic (fixed random seed in environment).
   Running evaluation multiple times on same model gives identical results.
